# AI-Powered Mobile Urban Intelligence Platform

This repository contains the **Frontend Prototype** for the SIH'26 project: *AI-Powered Mobile Urban Intelligence Platform Using Public Transport Fleet*.

## Purpose
This prototype serves as the visual and functional blueprint for municipal and transport authorities. It demonstrates how edge AI data (vehicle detection, potholes, congestion) generated by public transport buses is aggregated, filtered, and displayed on a centralized GIS dashboard.

## Tech Stack
- **React 18** + **Vite 6**
- **Tailwind CSS** (Styling & Layout)
- **React Router** (Navigation)
- **React-Leaflet** (GIS Map Integration)
- **Recharts** (Analytics & Dashboards)
- **Lucide React** (Iconography)

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone this repository (or open the project folder).
2. Navigate into the `frontend` directory:
   ```bash
   cd frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server
To spin up the local development server and view the prototype:
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`. The application will hot-reload as you make changes.

### Building for Production
To create a production-ready build (e.g., for Netlify, Vercel, or static hosting during your SIH presentation):
```bash
npm run build
```
The optimized static files will be generated in the `dist` folder. You can preview the production build locally with:
```bash
npm run preview
```

## Structure
- `src/components/`: Reusable UI elements (AlertPanel, MiniMap, KPICards).
- `src/pages/`: Main application views (Overview, GIS Map, Analytics).
- `src/data/mockData.js`: Centralized mock JSON data simulating the future backend API.
- `src/services/api.js`: Simulated asynchronous data fetching.

## Future Backend Integration
Once the AI Edge module and Backend API are developed, simply replace the `mockData.js` imports in `src/services/api.js` with actual `fetch` or `axios` calls pointing to your backend endpoints. The React components are built expecting this identical JSON schema.
