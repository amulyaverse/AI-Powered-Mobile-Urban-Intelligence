# Event Schema

This document outlines the conceptual schema for all events generated by the Edge AI modules. 

A common event format is critical because it ensures that the centralized backend and GIS dashboard remain modular and decoupled from the specific AI models. All AI modules (traffic, pothole, etc.) must eventually produce events using this structure.

## JSON Schema

```json
{
  "event_id": "",
  "event_type": "",
  "confidence": 0.0,
  "severity": "",
  "bus_id": "",
  "camera_id": "",
  "latitude": 0.0,
  "longitude": 0.0,
  "timestamp": "",
  "evidence": ""
}
```

### Field Descriptions
* **`event_id`**: Unique identifier for the generated event (e.g., UUID).
* **`event_type`**: Type of the detected event (e.g., "pothole", "congestion", "vehicle_count").
* **`confidence`**: AI model's confidence score for the detection (0.0 to 1.0).
* **`severity`**: Categorical severity of the event (e.g., "low", "medium", "high", "critical").
* **`bus_id`**: Identifier for the bus generating the event.
* **`camera_id`**: Identifier for the specific camera on the bus.
* **`latitude`**: GPS latitude at the time of detection.
* **`longitude`**: GPS longitude at the time of detection.
* **`timestamp`**: ISO 8601 formatted timestamp of when the event occurred.
* **`evidence`**: Link or base64 string of the image/video snippet proving the event.
